# Dapur Chaos Kuro

Game masak co-op ala Overcooked! 2: dapur chaos untuk 2 koki, **Raka** dan **Gora**.
Terima tiket pesanan, ambil bahan, cincang di talenan, masak patty (awas gosong!),
susun di piring, sajikan sebelum timer tiket habis, dan cuci piring kotor di wastafel.

Fitur: 3 resep (Burger, Salad, Burger Deluxe) + tip dari sisa waktu, skor bintang 1–3,
mode solo / co-op lokal 1 keyboard, multiplayer online 2 pemain (Buat Room / Gabung Room
pakai kode 5 karakter, WebRTC via PeerJS, host-authoritative), kontrol keyboard + sentuh
(HP landscape), audio prosedural Web Audio. Semua visual digambar pakai kode (Canvas 2D).

Satu file `index.html` mandiri — deploy statis di Vercel dari repo ini.
